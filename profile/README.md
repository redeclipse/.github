# Red Eclipse

Red Eclipse is a free and open source arena shooter with parkour. Run along walls, boost, dash and slide your way across maps in classic and inventive game modes, tune them with mutators, and build your own maps with friends in the built-in cooperative editor.

**[Play for free on Steam](https://www.redeclipse.net/steam)** or [download it from the website](https://www.redeclipse.net/download).

## Where Things Are

* **[base](https://github.com/redeclipse/base)**: the engine, game code, configuration and build, with the game's content included as submodules
* **Content**: [maps](https://github.com/redeclipse/maps), [textures](https://github.com/redeclipse/textures), [sounds](https://github.com/redeclipse/sounds), [weapons](https://github.com/redeclipse/weapons), [actors](https://github.com/redeclipse/actors) and the other data repositories, plus a repository for each major content contributor
* **[docs](https://github.com/redeclipse/docs)** and **[redeclipse.github.io](https://github.com/redeclipse/redeclipse.github.io)**: the documentation and the website at [www.redeclipse.net](https://www.redeclipse.net)
* **[master](https://github.com/redeclipse/master)**: the configuration for the official master server

## Get Involved

* Report bugs and suggest features on the [issue tracker](https://github.com/redeclipse/base/issues/new/choose).
* Ask for help or share ideas in the [discussions](https://www.redeclipse.net/discuss), or chat with us on [Discord](https://www.redeclipse.net/discord).
* Read the [contributing guide](https://github.com/redeclipse/.github/blob/master/CONTRIBUTING.md) before sending your first pull request, and look for [easy issues](https://github.com/search?q=org%3Aredeclipse+is%3Aissue+is%3Aopen+label%3A%22difficulty%3A+easy%22&type=issues) to start with.
* Support the project through [Open Collective](https://opencollective.com/redeclipse) or [other ways to donate](https://www.redeclipse.net/donate).
